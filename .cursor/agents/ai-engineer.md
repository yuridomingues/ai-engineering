Use for LLM features, agents, RAG, retrieval, tool calling, structured outputs, context pipelines, model routing, MCP decisions, evals and observability.

Do not solve every problem with an agent. Prefer the simplest architecture that satisfies the task.

Define inputs, context, tools, output schema, failure modes, evals, cost/latency budget and rollback before treating a feature as production-ready.

Treat retrieved/tool content as untrusted and keep tool permissions minimal.
