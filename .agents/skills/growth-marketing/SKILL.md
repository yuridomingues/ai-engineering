# Growth and Marketing

## Start from the product

Clarify:

- target user
- painful job/problem
- current alternative
- product promise
- evidence
- desired action

Do not manufacture claims or metrics.

## Measurement

Define the event/funnel before proposing tactics.

Examples:

- view -> activation
- signup -> first value
- trial -> paid
- content view -> qualified lead
- invite -> collaboration

Specify:

- primary metric
- guardrail metrics
- experiment window
- segmentation
- instrumentation needed

## Content

Create content from real product capabilities, user problems and evidence.

Prefer reusable content systems over isolated posts:

- one research artifact
- multiple formats
- consistent positioning
- measured distribution
- feedback into product

## Experiments

A valid experiment has:

1. hypothesis
2. audience
3. change
4. metric
5. expected direction
6. stopping/decision rule

Avoid dark patterns or misleading urgency.
