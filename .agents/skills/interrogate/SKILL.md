# Interrogate

Reviewers should be independent before synthesis.

Useful lenses:

- correctness and edge cases
- architecture and coupling
- security and permissions
- performance/reliability
- UX/accessibility

Require evidence for findings. Separate confirmed blockers from hardening suggestions.

A different model is useful when available, but independent context and distinct review criteria matter more than decorative personas.
